# MathForge

Offline Computer Algebra, Numerical Computing & Scientific Experimentation Platform.

## Installation (Windows)

1. Ensure you have Python 3.11+ and Node.js installed.
2. Clone the repository.
3. Run `scripts/setup_windows.ps1` to initialize the environment.

## Running

1. Run `scripts/run_backend.ps1` in one terminal.
2. Run `scripts/run_frontend.ps1` in another terminal.
3. Open `http://localhost:5173` in your browser.
